## 📝 Описание
Проект предназначен для новичков, изучающих Python с целью научится **визуализировать математические функции** с использованием профессиональных инструментов программирования.<br>
Он представляет собой учебную практическую работу по построению графиков различных функций с помощью библиотек **Matplolib** и **Ploty**.<br>
Проект охватывает **весь цикл** - от настройки рабочего окружения до генерации **статически** и **интерактивных графиков** и их публикации на **GitHub**.<br>
Особенность проекта: **максимально подробные инструкции**, чтобы даже человек, ранее не знакомый с программированием смог:<br>
- установить нужные библиотеки;<br>
- написать код на **Python**;<br>
- сохранить результат в виде PNG или HTML;<br>
- запустить Jupyter Notebook;<br>
- опубликовать график на GitHub и GitHub Pages (для просмотра с телефона).

### Установка (через терминал)

1. **Клонируйте репозиторий:**
Создайте локальную копию проекта из GitHub на вашем компьютере.

```bash

cd ~/matvey_mgri                                           # Переход в папку проекта "matvey_mgri" для просмотра данных
```

2. **Создайте и активируйте виртуальное окружение на вашем компьютере:** Это защитит системный Python от конфликтов и позволит изолированно устанавливать зависимости.
```bash
cd ..                                                      # Возврат в корневую папку проектов 
python3 -m venv venv_mgri                                  # Создание виртуального окружения с именем "venv_mgri"
source venv_mgri/bin/activate                              # Активация виртуального окружения (в начале строки терминала появится (venv_mgri))
```

3. **Установите зависимости:** После активации виртуального окружения установите необходимые библиотеки (или все указанные в requirements.txt)
```bash

```
Или установите большинство библиотек используемые в Python из файла **requirements.txt**. Их назначение в Разделе **Зависимости**
```bash
pip install -r requirements.txt
```

## 💻 Построение графиков

### Построение статического графика с сохранением в PNG (Matplotlib)
```python
# Импортируем библиотеку NumPy для работы с массивами и математическими функциями
import numpy as np

# Импортируем модуль pyplot из библиотеки Matplotlib для построения графиков
import matplotlib.pyplot as plt

# Задаём диапазон значений x от -5 до 15 с шагом 1.4 (включительно)
# Этот массив, содержит значения для которых будет строиться график
x_values = np.arange(-5, 15, 1.4)

# Исключаем из диапазона все значения x, которые меньше или равны 0 (x ≤ 0)
# Это необходимо, потому что логарифм от 0 и отрицательных чисел не существует
x_valid = x_values[x_values > 0]

# Вычисляем значения у по формуле логарифма по основанию 3:
# log₃(x) = ln(x) / ln(3), где ln - натуральный логарифм
y_values = np.log(x_valid) / np.log(3)

# Строим график функции y = log₃(x)
# Указываем красный цвет линии и подпись для легенды
plt.plot(x_valid, y_values, color='red', label='y = log₃(x)')

# Добавляем заголовок графика
plt.title('График функции y = log₃(x)')

# Подписываем оси графика
plt.xlabel('x')
plt.ylabel('y')

# Включаем отбражение сетки на графике
plt.grid(True)

# Отображаем легенду с подписью кривой
plt.legend()

# Сохраняем построенный график в файл формата .PNG
plt.savefig("graph_log3.png")
```

### Построение интерактивного графика с сохранением в HTML (Plotly)
```python
# Импортируем библиотеку NumPy для работы с массивами и математическими функциями (если еще не импортировали)
import numpy as np

# Импортируем модуль объектов графики из библиотеки Plotly
# Он позволяет создавать сложные интерактивные графики
import plotly.graph_objs as go

# Импортируем модуль для офлайн-отображения графиков в браузере
import plotly.offline as pyo

# Задаем значения по оси X - от 1 до 15 включительно с шагом 1
x = np.arange(1, 16, 1)

# Вычисляем значения Y - логарифм по основанию 3 от X
# Используем формулу log₃(x) = ln(x) / ln(3)
y = np.log(x) / np.log(3)

# Создаем график: указываем, что нужно соединить точки линиями и добавить маркеры
# Красный цвет используется для наглядности, а name - подпись графика в легенде
trace = go.Scatter(
    x=x,
    y=y,
    mode='lines+markers',
    name='y = log₃(x)',
    line=dict(color='red')
)

# Определяем макет (оформление) графика: заголовок, подписи осей и шаблон
layout = go.Layout(
    title='Интерактивный график функции y = log₃(x)',
    xaxis=dict(title='x'),
    yaxis=dict(title='y'),
    template='plotly_white'
)

# Объединяем данные и макет в один объект Figure
fig = go.Figure(data=[trace], layout=layout)

# Сохраняем график как HTML-файл и автоматически открываем его в браузере
pyo.plot(fig, filename='interactive_log3.html')
```
