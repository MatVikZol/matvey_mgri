## 📝 Описание
Проект предназначен для новичков, изучающих Python с целью научится **визуализировать математические функции** с использованием профессиональных инструментов программирования.<br>
Он представляет собой учебную практическую работу по построению графиков различных функций с помощью библиотек **Matplolib** и **Ploty**.<br>
Проект охватывает **весь цикл** - от настройки рабочего окружения до генерации **статически** и **интерактивных графиков** и их публикации на **GitHub**.<br>
Особенность проекта: **максимально подробные инструкции**, чтобы даже человек, ранее не знакомый с программированием смог:<br>
- установить нужные библиотеки;<br>
- написать код на **Python**;<br>
- сохранить результат в виде PNG или HTML;<br>
- запустить Jupyter Notebook;<br>
- опубликовать график на GitHub и GitHub Pages (для просмотра с телефона).

## ✨ Возможности
- **Изучение основ визуализации данных на Python**<br>

### Установка (через терминал)

1. **Клонируйте репозиторий:**
Создайте локальную копию проекта из GitHub на вашем компьютере.

```bash
mkdir -p ~/git                                             # Создание корневой папки для хранения всех проектов с GitHub на компьютере.
cd ~/git                                                   # Переход в созданную папку
git clone https://github.com/MatVikZol/matvey_mgri.git     # Загрузка (клонирование) проекта в папку с репозитория GitHub
cd ~/matvey_mgri                                           # Переход в папку проекта "matvey_mgri" для просмотра данных
```

2. **Создайте и активируйте виртуальное окружение на вашем компьютере:** Это защитит системный Python от конфликтов и позволит изолированно устанавливать зависимости.
```bash
cd ..                                                      # Возврат в корневую папку проектов 
python3 -m venv venv_mgri                                  # Создание виртуального окружения с именем "venv_mgri"
source venv_mgri/bin/activate                              # Активация виртуального окружения (в начале строки терминала появится (venv_mgri))
```

3. **Установите зависимости:** После активации виртуального окружения установите необходимые библиотеки (или все указанные в requirements.txt)
```bash
pip install matplotlib numpy ploty
```
Или установите большинство библиотек используемые в Python из файла **requirements.txt**. Их назначение в Разделе **Зависимости**
```bash
pip install -r requirements.txt
```

## 💻 Использование

### Вариант 1: Статический график (Matplotlib)
```python
import numpy as np
import matplotlib.pyplot as plt

# Задаём диапазон значений x от -5 до 15 с шагом 1.4
x_values = np.arange(-5, 15, 1.4)

# Вычисляем значения y = log base 3 (x), исключая некорректные x ≤ 0
x_valid = x_values[x_values > 0]
y_values = np.log(x_valid) / np.log(3)  # логарифм по основанию 3

# Строим график
plt.plot(x_valid, y_values, color='red', label='y = log₃(x)')
plt.title('График функции y = log₃(x)')
plt.xlabel('x')
plt.ylabel('y')
plt.grid(True)
plt.legend()

# Сохраняем результат в файл
plt.savefig("graph_log3.png")
```

### Вариант 2: Интерактивный график (Plotly)
```python
import numpy as np
import plotly.graph_objs as go
import plotly.offline as pyo

# Создание значений x
x = np.arange(1, 16, 1)
y = np.log(x) / np.log(3)  # логарифм по основанию 3

# Построение интерактивного графика
trace = go.Scatter(x=x, y=y, mode='lines+markers', name='y = log₃(x)', line=dict(color='red'))
layout = go.Layout(
    title='Интерактивный график функции y = log₃(x)',
    xaxis=dict(title='x'),
    yaxis=dict(title='y'),
    template='plotly_white'
)
fig = go.Figure(data=[trace], layout=layout)

# Сохранение и автоматическое открытие в браузере
pyo.plot(fig, filename='interactive_log3.html')
```
